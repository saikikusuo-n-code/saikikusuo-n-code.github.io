# Saiki's Devblog

This is my devblog which documents software modifications, tutorials, development works and other. This includes things in my personal time and company work, written to be useful to me and to whoever finds their way here through a search engine...

## What you can find?

The blog primarily focuses on hands-on technical work, including:

* **Software modification**: changes made to existing applications or system component
* **Tutorial**: instructions for configuring, modifying, building or troubleshooting software
* **Devnotes**: implementation details, design decisions and lessons learned during development
* **Customization**: adapting to specific hardware, platforms, interfaces or requirements
* **Debugging**: investigating unexpected behavior, identifying root causes and documenting solutions
* **Tools and scripts**: automation scripts and development tools created to simplify repetitive or specialized tasks
* **Technical references**: useful information about APIs, file formats, build systems, configuration files, development environments, and other software-related subjects
* **Updates**: version notes, migrations; when a tool, library or workflow shifts in a way that isn't obvious from the official changelog, I capture what broke, what I changed and why

If possible, articles include source-code examples, configuration snippets, command-line instructions, diagrams, images, and explanations. Complex changes are broken down into smaller steps.

For **Software modification** and **Devnotes** we have kernel patches, driver modifications, build system changes, envrionment changes etc.

For **Tutorial**, they range from setting up development environments and flashing to integrating tools (example redmine + vscode).

## Target of my page!

This is written for who are interested in electronics' software: embedded systems, Linux kernel and driver development, Android framework and apps, factory and servicing tools.

## Organization

On the left side of the page you see categories, you can filter published page by what you need. Including search, they are the fastest ways to find something specific. You can also search in reverse chronological order.

Code blocks are meant to be copy-paste friendly. Where a command requires adjustment for your environment, the relevant variables are called out explicitly rather than buried in prose.

## Accuracy

Please note that pages will be updated on sudden changes! See the UPDATE blocks of page (if existing) if anything goes wrong; there might be a change somewhere.
