This is my devblog which documents software modifications, tutorials, development works and other. This includes things in my personal time and company work...

## What you can find?

The blog primarily focuses on hands-on technical work, including:

* **Software modification**: changes made to existing applications or system component
* **Tutorial**: instructions for configuring, modifying, building or troubleshooting software
* **Devnotes**: implementation details, design decisions and lessons learned during development
* **Customization**: adapting to specific hardware, platforms, interfaces or requirements
* **Debugging**: investigating unexpected behavior, identifying root causes and documenting solutions
* **Tools and scripts**: automation scripts and development tools created to simplify repetitive or specialized tasks
* **Technical references**: useful information about APIs, file formats, build systems, configuration files, development environments, and other software-related subjects

If possible, articles include source-code examples, configuration snippets, command-line instructions, diagrams, images, and explanations. Complex changes are broken down into smaller steps.
